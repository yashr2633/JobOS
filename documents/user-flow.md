# JobOS User Flow

Version: 1.0
Status: Locked (MVP)

---

# Goal

Help users track every job application from one dashboard and receive AI-powered insights on what to do next.

---

# User Journey

## 1. Landing Page

User visits JobOS.

Options:

- Sign in with Google
- Sign in with Email

↓

## 2. Account Creation

User creates an account.

↓

## 3. Welcome Screen

JobOS explains:

- Track every application
- AI Resume Analysis
- AI Job Match
- Follow-up Reminders

↓

Continue

↓

## 4. Resume Upload (Optional)

User can:

- Upload Resume
- Skip for now

If uploaded:

- Resume is parsed
- ATS score generated

↓

## 5. Dashboard (Home)

User sees:

- Total Applications
- Applied
- Interviews
- Offers
- Rejected
- Ghosted
- Upcoming Follow-ups

Primary Actions:

- Add Job
- Import Job URL
- Connect Gmail (Coming Soon)
- Upload Resume

↓

## 6. Add Job

Three methods:

1. Paste Job URL
2. Manual Entry
3. Gmail Import (Future)

↓

Job is created.

↓

## 7. Job Analysis

JobOS extracts:

- Company
- Role
- Skills
- Experience
- Location

↓

AI compares Resume ↔ JD.

Outputs:

- Match Score
- Missing Skills
- Strengths
- Weaknesses
- Improvement Suggestions

↓

## 8. Application Tracking

User updates status:

Saved

↓

Applied

↓

Interview

↓

Offer

OR

Rejected

OR

Ghosted

↓

Timeline updates automatically.

↓

## 9. Follow-up Reminder

If no update after selected period:

JobOS suggests:

- Send Follow-up
- Mark Ghosted

↓

## 10. Application Details

Shows:

- Job Information
- Resume Used
- Match Score
- AI Rejection Analysis
- Notes
- Timeline
- Follow-up History

↓

User edits whenever needed.

↓

## 11. Notifications

Examples:

- Interview Tomorrow
- Follow-up Due
- Resume Match Ready
- New Analysis Complete

↓
