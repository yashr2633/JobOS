# JobOS Roadmap

This is the sequencing view of backlog.md — same features, organized by *when*, not just *what*.

---

## Milestone 0 — Foundation (current)
- [x] vision.md, prd.md, backlog.md, competitors.md written
- [ ] Tech stack decided
- [ ] Database schema created
- [ ] GitHub repo initialized
- [ ] Basic project skeleton running locally

## Milestone 1 — MVP Build (Phase 1 features)
- [ ] Auth (login/signup)
- [ ] Unified Job Dashboard (empty state → populated state)
- [ ] Manual Job Add
- [ ] Manual Job URL Import (AI-parsed)
- [ ] Gmail Import
- [ ] Resume Upload
- [ ] Resume ↔ JD Match Score
- [ ] AI Rejection Analysis
- [ ] Follow-up Reminders

## Milestone 2 — MVP Launch
- [ ] Deploy to production (Vercel + Supabase, or chosen stack)
- [ ] Get first 10–20 real users (friends, LinkedIn, college network)
- [ ] Collect feedback, fix critical bugs
- [ ] Decide: keep going as-is, or pivot based on what users actually use

## Milestone 3 — Phase 2 (only after real usage data exists)
- [ ] Interview Copilot
- [ ] Cover Letter Generator
- [ ] AI Resume Rewrite
- [ ] Analytics
- [ ] Browser Extension

## Milestone 4 — Phase 3 (post-growth)
- [ ] AI Career Coach
- [ ] Career Health Score
- [ ] Company Research
- [ ] Salary Insights
- [ ] Referral Network

---

## Rule

Do not start a milestone before the previous one is shipped and has real users on it. Skipping ahead is the #1 way this kind of project stalls.
