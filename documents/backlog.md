## Decision Rule for New Features

Before adding anything to Phase 1, ask:
1. Does this solve the user's single biggest problem?
2. Is the app incomplete without it?
3. Does it add more than 1–2 weeks of extra dev time?

- **Yes, necessary** → Phase 1
- **Good, but not necessary** → Phase 2
- **Long-term vision** → Phase 3

This rule exists to prevent scope creep. MVP stays small on purpose.
